# រៀន Bootstrap ពីមូលដ្ឋានដល់កម្រិតខ្ពស់

វគ្គ Bootstrap ជាភាសាខ្មែរ មានមេរៀន ១៨ ជំពូក និង project អនុវត្ត។ រៀនបន្តពី HTML/CSS មូលដ្ឋាន; Bootstrap ជា frontend toolkit មិនមែនជំនួស HTML, CSS ឬ JavaScript ទេ។

**កំណែគោលសម្រាប់វគ្គនេះ៖ Bootstrap 5.3.9។** បើឯកសារផ្លូវការចេញ version ថ្មី សូមកែ version និងពិនិត្យ migration guide មុនធ្វើបច្ចុប្បន្នភាព។ Bootstrap 5 មិនត្រូវការ jQuery; bundle JavaScript រួម Popper សម្រាប់ dropdown, tooltip និង popover។
