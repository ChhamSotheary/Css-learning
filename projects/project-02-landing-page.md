# Project 2៖ Responsive Landing Page

**កម្រិត៖ Intermediate**  
**មេរៀនពាក់ព័ន្ធ៖** 7–13

## គោលបំណង
បង្កើត landing page សម្រាប់ផលិតផល ឬសេវាកម្ម ដោយមាន navigation, hero, features, call-to-action និង footer។

## តម្រូវការ
- Header និង nav ប្រើ semantic HTML។
- Hero មានចំណងជើង, ព័ត៌មានខ្លី, action link/button និងរូបភាព។
- Feature cards រៀបដោយ CSS Grid; header/toolbar អាចប្រើ Flexbox។
- ប្រើ container max-width និង fluid spacing។
- Mobile-first; រូបភាពមិនលើស parent។
- Sticky/fixed navigation ប្រើតែបើមិនបាំង content និង keyboard focus។
- ប្រើ design palette និង typography ស្របគ្នា។

## ជំហាន
1. កំណត់ content hierarchy និង wireframe mobile/desktop។
2. សរសេរ HTML semantic និងតំណភ្ជាប់ដែលមានអត្ថន័យ។
3. កំណត់ CSS tokens មូលដ្ឋាន។
4. បង្កើត hero/layout ដោយ grid/flex។
5. បន្ថែម media query តាមពេល content មិនសម។
6. សាក breakpoints, image crop, keyboard navigation, zoom និង long Khmer copy។

## Checklist
- [ ] Content សំខាន់អាចអានដោយគ្មាន image។
- [ ] CTA មាន label ច្បាស់; action ប្រើ button, navigation ប្រើ link។
- [ ] Layout mobile/tablet/desktop មិន overlap។
- [ ] មាន hover និង focus-visible states។
- [ ] រូបភាពមាន alt និងទំហំ/ratio សម។
- [ ] គ្មាន color-only instruction។
