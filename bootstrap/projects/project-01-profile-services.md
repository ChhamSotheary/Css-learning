# Project 1៖ Responsive Profile និង Services Page

**កម្រិត៖ Beginner | Chapters 01–08**

## គោលដៅ
បង្កើតទំព័រ profile មាន header, profile card, introduction និង services 3 មុខ។

## Requirements
- ភ្ជាប់ Bootstrap CSS តាម CDN ឬ npm។
- ប្រើ container, grid, typography និង spacing utilities។
- មាន profile image ជាមួយ alt សមស្រប; decorative image ប្រើ alt ទទេ។
- Services បង្ហាញជាកាត 1 ជួរឈរលើ mobile និងច្រើនជួរឈរលើ desktop។
- ប្រើ semantic heading, links/buttons ត្រឹមត្រូវ និង focus-visible។
- Khmer font/line-height អានបាន។

## ជំហាន
1. សរសេរ HTML semantic ដោយមិនដាក់ class ច្រើនមុន។
2. កំណត់ page sections និង grid layout។
3. ប្រើ Bootstrap utility សម្រាប់ spacing និង responsive behavior។
4. បន្ថែម class ផ្ទាល់ខ្លួនតិចៗសម្រាប់ profile card/theme។
5. សាកទទឹង 320px, desktop, keyboard និង zoom 200%។
