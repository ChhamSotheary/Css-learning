# Project 1៖ Profile Card

**កម្រិត៖ Beginner**  
**មេរៀនពាក់ព័ន្ធ៖** 1–8

## គោលបំណង
បង្កើត profile card ដែលបង្ហាញឈ្មោះ, តួនាទី, ការណែនាំខ្លី និង link/contact action។

## តម្រូវការ
- HTML មាន main/article/heading ត្រឹមត្រូវ។
- រូប profile មាន alt text ដែលពិពណ៌នាសមស្រប; បើរូបតុបតែងសុទ្ធ alt=""។
- ប្រើ external stylesheet។
- Card មាន max-width, padding, border, radius និង shadow ស្រាល។
- ប្រើ font stack គាំទ្រខ្មែរ និង line-height អានងាយ។
- Link មាន hover និង focus-visible state ដែលឃើញច្បាស់។
- Layout មិនលើស viewport នៅទទឹងតូច។

## ជំហាន
1. សរសេរ markup ដោយមិនទាន់តុបតែង។
2. បង្កើត CSS reset ស្រាល និង box-sizing:border-box។
3. កំណត់ colors/type/spacing សាមញ្ញ។
4. រៀប card ដោយ margin-inline:auto និង max-width។
5. សាក hover, keyboard tab, 320px viewport និង zoom 200%។

## លទ្ធផលដែលត្រូវបង្ហាញ
បន្ថែម screenshot desktop/mobile និង paragraph ខ្លីពន្យល់ selector, box model និង unit ដែលបានប្រើ។
