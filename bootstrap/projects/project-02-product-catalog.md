# Project 2៖ Product Catalog / Shop UI

**កម្រិត៖ Intermediate | Chapters 03–13**

## គោលដៅ
បង្កើត catalog មាន responsive navbar, search/filter form, product grid, cards, badge, pagination និង alerts។

## Requirements
- Product grid ប្រើ Bootstrap row/col ឬ row-cols responsive classes។
- Product cards មាន image, title, price, badge និង action link/button។
- Form controls មាន label, help/error messages និង responsive layout។
- Filter/sort controls មាន semantic controls; ប្រសិនបើ filter ពិតត្រូវដំណើរការ សូមបន្ថែម JavaScript behavior។
- Navbar collapse ដំណើរការដោយ Bootstrap bundle និងមាន aria attributes។
- Light/dark colors អានបាន; error/status មិនពឹងលើ color តែមួយ។
- Images កំណត់ size/ratio និង alt។

## ជំហាន
1. រៀប product markup និង data ឱ្យស្របគ្នា។
2. បង្កើត header/navigation និង responsive collapse។
3. រៀប filter form ជាមួយ labels និង grid។
4. បង្កើត product cards, badges និង responsive columns។
5. បន្ថែម pagination និង empty/error/success states។
6. សាក keyboard, breakpoints, long title, missing image និង form error states។

## Checklist
- [ ] Toggler ទទួលបាន keyboard focus និង accessible name។
- [ ] Product cards មាន heading hierarchy និង links មានន័យ។
- [ ] Grid stack ត្រឹមត្រូវលើ mobile។
- [ ] Form labels ភ្ជាប់ទៅ input។
- [ ] Bootstrap JS loaded តែ behavior ដែលត្រូវប្រើ។
- [ ] ពន្យល់ classes និង breakpoints ក្នុង project README។
