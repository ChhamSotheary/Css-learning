# Complete CSS Course: Basic to Advanced

វគ្គរៀន CSS ជាភាសាខ្មែរ ពីមូលដ្ឋានដល់កម្រិត Advanced/Expert។ មេរៀនប្រើ technical terms ជាភាសាអង់គ្លេស ហើយមានគោលបំណង, ពន្យល់, syntax, ឧទាហរណ៍, ការអនុវត្ត, លំហាត់ និងចម្លើយពិនិត្យខ្លួនឯង។

## របៀបរៀន

1. រៀនតាមលំដាប់ Chapter 01 → 22។
2. អនុវត្តកូដក្នុង browser ហើយប្រើ DevTools មើល computed styles និង layout។
3. កុំរំលង HTML semantic និង keyboard accessibility ព្រោះ CSS មិនអាចជំនួសរចនាសម្ព័ន្ធ HTML បាន។
4. បន្ទាប់ពី Chapter 06, 12, 18 និង 22 ធ្វើ project ដែលពាក់ព័ន្ធ។
5. សាក viewport តូច, zoom, keyboard និងអត្ថបទខ្មែរជានិច្ច។

**តម្រូវការមុនចាប់ផ្តើម៖** ស្គាល់ HTML មូលដ្ឋាន ដូចជា heading, paragraph, link, image, list, form និង semantic tags។ បើមិនទាន់ សូមរៀន HTML មូលដ្ឋានជាមុន។

## អ្នកនឹងអាចធ្វើអ្វីក្រោយបញ្ចប់?

អ្នកនឹងអាចជ្រើស selectors, គ្រប់គ្រង cascade និង box model, បង្កើត layouts ដោយ Flexbox/Grid, ធ្វើ responsive pages, បង្កើត interactions និង animations, រៀបចំ design tokens/components និងពិនិត្យ accessibility។ CSS expertise កើតពីការសាងសង់ និងកែលម្អ project ពិត; មេរៀនទាំងនេះជាមូលដ្ឋានសម្រាប់ការអនុវត្តបន្ត។
